# 7–10 minute demo flow
1. Introduce CareerConnect and the problem (40 sec).
2. Show homepage and responsive navigation (50 sec).
3. Register/login as candidate (60 sec).
4. Search/filter and open job details (60 sec).
5. Apply and show candidate dashboard (60 sec).
6. Login as recruiter; create/edit a listing and view applicants (90 sec; finish this workflow first).
7. Show Postman requests and MongoDB records (60 sec).
8. Demonstrate invalid token and wrong-role denial (60 sec).
9. Show 375px mobile layout and GitHub repository (50 sec).
10. Show actual deployment URLs, test evidence, limitations and future scope (60 sec).
Record the running application, not only slides or screenshots.
